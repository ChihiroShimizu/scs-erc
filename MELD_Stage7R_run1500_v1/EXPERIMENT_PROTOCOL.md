# MELD Stage7R：固定实验方案

## 核心假设与对照

研究目标是检验额外结构标注是否帮助LLM使用局部历史理解当前情绪。沿用服务器Stage7的标签监督证据规划和情绪分类实现，保持Qwen2.5-7B-Instruct和LoRA结构。规划阶段看到当前句和此前最多三轮；分类阶段看到所选证据及预测结构。模型推理不获得教师标注或gold情绪。

唯一主要比较：完整结构监督与仅情绪标签继续训练之间，五种子平均dev weighted F1的差值。

| 方法 | 训练与推理 | 用途 |
|---|---|---|
| 基础当前句 | 新基础emotion adapter，当前句分类 | 普通基线 |
| 基础前三轮 | 同一基础adapter，提供前三轮 | 固定历史基线 |
| 不确定时参考历史 | 沿用旧核心的train-calibration拟合阈值 | 辅助对照，不是本轮方法贡献 |
| 仅情绪标签继续训练 | 同一1200目标，无教师结构；推理提供前三轮 | 排除额外分类训练本身的收益 |
| 需求与证据监督 | context_need、所选证据ID与效用，另训练情绪 | 检验简化证据监督 |
| 完整监督 | 完整规划字段及情绪训练 | 主方法 |
| 打乱监督 | 训练区内合法重映射的语义打乱标签 | 检验正确语义标签的贡献 |
| 完整训练，分类只读证据 | 同一full adapter、同一缓存完整计划，但分类不读结构字段 | 推理字段消融 |

额外机制诊断：同一full adapter、统一中性分类提示，分别提供零条历史、全部前三轮、自预测计划所选的最多一轮。三条路径只改变历史文本；不提供结构字段。该诊断不新增训练或可部署策略。

## 数据与质量

五个结果包均300条；合并后1500个唯一目标、866个对话。教师分布为 current_sufficient=931，history_helpful=256，history_required=129，ambiguous=184；自审kept=1376、reannotated=124。所有记录通过当前schema、候选覆盖/顺序、说话人、距离、证据合法性、最终标注一致性、分数加总与通过条件检查。

这不代表独立语义核验已完成，不把教师置信度或分数当人类准确率。原始五包可继续留存，本包 source_provenance.json 记录其哈希及可用运行信息，不猜测精确教师模型版本。

服务器使用原Stage7对官方train全部对话的稳定哈希划分，seed=2026，10%对话用于calibration。必须复现1200个教师train目标与300个教师calibration目标；否则中止。基础情绪训练及所有回放也必须排除校准对话的全部目标。

服务器逐条比对盲输入与实际train文本/历史，并锁定train、validation文件哈希。test不读取。dev已用于前期方法开发，本轮仍为开发集重跑，不宣称未触碰的盲测。

## 训练安排

种子42/43/44/45/46；基础adapter600步；四个独立分支各480步。LoRA r=16、alpha=32、dropout=0.05；微批1、梯度累积16。基础学习率2e-5；分支1e-5；warmup20。模型、tokenizer、打分和训练循环调用服务器原实现。

每个教师目标在完整/证据/打乱分支有一条规划、一条情绪分类及一条共享情绪回放，共3600条任务记录。label-only分支有两条同提示的情绪分类及同一条共享回放，也是3600条。重复分类不算新的独立样本。报告监督token和任务计数，不把等步数、等记录数称为等算力。

所有分支从同一种子的本轮基础adapter独立开始；各有独立优化器、scheduler和随机状态。父权重前后哈希一致性检查，产物不会写回旧Stage7目录。固定480步结果作为主结果，不按dev挑checkpoint；本实现没有160/320步中间checkpoint选择。

本轮不自动复用旧500条实验adapter。中断后只跳过输入和权重身份验证通过的已完成分支。未完成分支从其固定父adapter重跑，不从不完整optimizer状态继续。

## 评估与统计

沿用候选标签打分；温度、原有不确定性阈值仅在train-calibration拟合。校准教师仅用于机制诊断，不进入SFT。机制路径使用缓存的相同预测计划，避免重新生成导致路径差异。

报告每种子weighted F1、固定7类Macro F1、Accuracy、NLL、Brier、ECE；均值及样本SD（ddof=1）。每类precision、recall、F1和support；每种子混淆矩阵。300条教师留出记录上另报告历史需求precision/recall/F1、不必要历史选择率、证据ID一致率和parse成功率。

主统计对象为**各训练种子成绩的平均差**：在每次bootstrap中同步抽取对话，分别重算每个种子F1，再平均差值。10,000次、seed=20261021、百分位95%CI。不把不同种子的同一目标当独立目标，也不平均概率后作ensemble。

主比较附100,000次对话级双侧配对随机置换（seed=20261022，加一修正），同一对话的交换掩码跨种子共享。仅主比较作确认性解释，其余比较CI为探索性、未多重校正。

原核心汇总使用跨种子平均概率后bootstrap，估计对象与表内均值可能不同；本包使用独立汇总模块统一统计对象，保留原模型训练和推理算法。

置信区间跨零时不宣称优于对照，也不宣布等效。种子SD下降不能替代配对差值证据。扩大标注不保证显著性；新训练预算和修订prompt也使旧500条对新1500条的直接比较不能纯粹归因于数量。
